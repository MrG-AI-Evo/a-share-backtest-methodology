# Web V1 产品、接口与体验规范

## 1. 产品定位

Web 是“打开即可看”的本地投研终端，不是 AI 聊天产品，也不是复杂交易客户端。默认路径只回答四件事：今天市场怎样、AI 在关注什么、组合风险怎样、某只股票的证据与研究是什么。

V1 运行条件：FastAPI/Python 服务和 Next.js 服务启动；Codex、ChatGPT、云服务与模型 API 均不需要常驻。

## 2. 全局信息架构

桌面导航：`市场 / 自选与候选 / 模拟组合 / 决策历史 / 系统状态`；全局搜索直接跳转证券详情。

手机/iPad：底部/紧凑导航保留 `市场 / 自选 / 组合 / 更多`；搜索置于页面顶部。主页面不出现聊天框。

每页必须显示：页面级 `as_of`、最近成功刷新、数据质量、主要来源；局部卡片如时间不一致则独立显示。

## 3. 首页 `/`

### 3.1 桌面布局

第一屏按阅读优先级：

1. 顶部状态条：交易阶段、当前时间、数据更新时间、源健康/降级。
2. 六指数条：上证、深证成指、创业板、科创50、沪深300、中证1000。
3. 市场宽度 + 成交额卡。
4. 行业/概念板块排行。
5. AI 今日关注表。
6. 模拟账户摘要 + 净值曲线。

建议 12 列网格：指数占 12；宽度 5 + 板块 7；AI 关注 8 + 账户 4。高度随内容，不为“卡片对齐”截断重要风险。

### 3.2 指数卡

字段：`name, symbol, last, change, change_pct, turnover, as_of, source`。当前点位和涨跌是主视觉，成交额/时间是次级。无数据时显示 `—` 和原因，不显示 0。

### 3.3 市场宽度

字段：上涨、下跌、平盘、涨停、跌停、全市场成交额、昨日成交额、变化额/变化率。总数不闭合时标 degraded，并显示未覆盖证券数。

### 3.4 板块

标签页：行业 / 概念；视图：涨幅 Top10 / 跌幅 Top10。列：名称、涨跌幅、成交额、热度、上涨/成分覆盖。热度必须有确定性公式版本和 tooltip，不可作为不透明 AI 分数。

### 3.5 AI 今日关注

列：名称/代码、现价、今日涨跌、AI 分数、状态、核心逻辑、最大风险、研究时间。状态枚举：`重点观察 / 观察 / 谨慎 / 排除`。默认按状态优先级、分数、更新时间排序。

点击行进入个股页。研究过期仍展示最近版本，但整行显示 stale，禁止无提示隐藏。

### 3.6 模拟账户

字段：初始资金、总资产、现金、持仓市值、总收益、当日收益、最大回撤、仓位、持仓数。净值曲线同时显示沪深300归一化基准；tooltip 显示日期、净值、基准和回撤。

### 3.7 当前流水线展示

- `/watchlist` 在人工自选之外只读展示最新通过 Schema 的确定性 Top30；没有正式产物时显示空态，不用演示数据替代。
- `/system` 展示当前实际接入的数据源及研究上游的安装/运行模式、最新筛选、研究评测通过/失败、账本闭合及永久关闭的实盘/模型开关；并展示低 Token 确定性任务的默认禁用状态、最近手动运行、截止时间、规则版本、输入哈希、处理计数、阻断和可导出的例外证据包。
- Web 不提供“运行 TradingAgents/UZI”按钮；V1 由 ChatGPT 或本地 CLI 生成版本化文件。

## 4. 个股页 `/stocks/[symbol]`

### 4.1 顶部行情

名称/代码/交易所/板块、现价、涨跌/幅、成交额、换手、PE(TTM)、PB、总市值、流通市值、交易状态、来源/时间。估值为空时说明语义（例如亏损导致 PE 不适用）。

### 4.2 图表工作区

时间维度：分时、日、周、月。指标开关：MA、MACD、RSI、BOLL；成交量始终可见。周/月线由后端按交易日聚合，前/后复权切换明确显示；切换不改变研究卡所用口径。

ECharts 要求：

- K 线、分时、成交量、净值 `animation: false`。
- 红涨绿跌并以数值符号辅助；十字光标、缩放、tooltip 键盘/触控可用。
- 单指纵向滚动页面优先；图表激活后单指查看、双指缩放；提供 reset。
- 数据更新不重置 zoom/当前选择，不用闪烁/滚动数字提示。
- 空/错误/降级态覆盖在图表区域并保留最近有效图形的时间说明。

### 4.3 AI 研究卡

头部：综合评分、状态、研究周期、置信度、数据新鲜度、最后研究时间、版本选择。

正文：一句话摘要、核心逻辑、多头证据、空头证据、催化剂、风险、失效条件、模型备注。

证据层级：

- `🟢 已确认事实`：内容、as_of、来源、evidence_id。
- `🟡 AI分析/推断`：内容、置信度、支持/反证 evidence。
- `🔴 风险或未验证信息`：风险/未知、影响、待验证动作、时限。

三种语义使用图标、标题和色彩，保证色觉差异用户能读懂。历史版本按时间倒序；切换版本时页面明确进入“历史研究”状态，不能误认为最新。

## 5. 其他页面

### `/watchlist`

自选和候选按漏斗阶段分组。支持搜索添加/移除自选（可撤销）、排序和筛选；不提供批量 LLM 分析按钮。候选阶段和分数变化显示 reason code；Top30 表必须显示运行时点，合成黄金样本不得进入正式展示目录。

### `/portfolio`

账户摘要、持仓表/卡、行业/主题暴露、净值/回撤、未来事件、订单/成交。任何模拟订单变更必须显示研究版本、规则检查和人工批准状态。

### `/decisions`

按时间串联 `研究 → 建议 → 批准/拒绝 → 订单 → 成交 → 复盘`。支持标的/日期/状态筛选；审计记录只读。

### `/system`

本地服务、数据源 SLA、缓存、最近成功/失败、adapter 模式、研究评测、账本闭合、研究导入错误、规则版本、数据库/备份状态，以及确定性运行时状态。

确定性运行时只能呈现只读控制面：任务是否启用、最近手动运行时间、数据截止时间、执行耗时、输入哈希、规则版本、股票/候选/买卖计数、阻断项、异常项和只读导出的例外证据包。不得提供“启用调度”“调用模型”“执行实盘”按钮。

年度统计只可从正式主回测闭合检查点读取，并展示：年末总资产、年度净盈亏、截至该年累计盈亏和仅作归因的分红/费用/税费/滑点。没有正式检查点必须明确空态；不得以演示值代替。滑点若仅嵌入成交价格而没有独立账本金额，显示“未独立记录”，不得反推或补造金额。不得显示凭据、Cookie 或完整敏感日志。

### `/backtests`

- 正式回测就绪门、数据覆盖、运行记录与机制测试报告必须分层展示，机制测试不得混入正式运行列表或改写正式就绪状态。
- 11 股机制测试报告只读取通过 Schema、源结果 SHA-256 和账本闭合校验的只读 JSON；首屏必须显示“机制测试 · 非正式绩效”和事后选样偏差。
- 报告至少展示：期末资产、外部投入、总盈亏、XIRR、TWR、最大回撤、年度/累计盈亏、个股贡献、数据覆盖和哈希链状态。
- 年度与个股正负值使用红正绿负，但必须同时显示正负号和文字；ECharts `animation: false`，并用数据表提供等价的可访问内容。

## 6. 响应式与触控验收

### 手机（390×844 与 430×932）

- 单栏；指数可横向明确分页或 2×3 卡片，不造成整页横滚。
- 市场宽度压缩为 2–3 列指标；板块表转为排行卡。
- AI 关注先显示名称、涨跌、状态、分数、风险；逻辑展开查看。
- 账户先显示总资产、收益、回撤、仓位；净值图最小高度 220px。
- 固定导航不遮挡内容，适配 `env(safe-area-inset-*)`。

### iPad（768×1024、820×1180、1024×1366，横竖屏）

- 竖屏 1–2 列，横屏 2–3 列；详情页图表与研究卡可上下或 7:5 分栏。
- 不把桌面 12 列按比例缩小；表格根据可读宽度切换简化列。
- Apple Pencil/触控与鼠标均可操作；不依赖 hover 才能看到来源或 tooltip。

### 触控规则

- 可点击区域 ≥44×44px，相邻高风险操作间距 ≥8px。
- `touch-action` 按图表/滚动容器精确设置；禁止全页 `preventDefault`。
- 点击反馈即时；操作提交仍在松手/确认后发生。
- 破坏性操作只存在于模拟数据管理且需要确认/撤销，不用复杂 swipe 手势隐藏关键操作。

## 7. 视觉系统

- 情绪：冷静、可信、效率优先；暗色为默认，浅色跟随系统可选。
- 字体：`system-ui` 中文系统字体栈；金额/价格/日期使用 `font-variant-numeric: tabular-nums`。
- 密度：桌面紧凑但点击区不缩小；分隔优先留白、弱边框和对齐，不堆厚重阴影。
- 色彩：红涨绿跌；警告/未知不能复用涨跌颜色作为唯一语义。
- 层级：只有浮层/粘性工具条可使用轻微半透明，正文卡片保持稳定高对比。
- 文案：短、直接、具体；`更新时间 15:00:05` 优于“数据较新”。

## 8. 动效预算

这是每天高频使用的金融终端，默认“无动画”。

允许：

- press/tap feedback：100–160ms，`scale(0.97)`，只在按压时。
- tooltip/popover：125–180ms，origin-aware，opacity + `scale(0.97)`，强 ease-out。
- 偶发 toast：200ms 内进入、退出更快，同边进出。
- accordion：仅低频详情，短 opacity/transform；不能阻塞阅读。

拒绝：行情 number ticker、K 线路径绘制、排行重排飞行动画、页面 parallax、背景循环、hover 放大数据卡、键盘导航动画、超过 300ms 的常规 UI 动效。

所有移动变换提供 `prefers-reduced-motion` 淡入/静态替代；hover 动效只在 `(hover: hover) and (pointer: fine)`。

## 9. 数据五态

每个核心模块都有：

- `loading`：稳定骨架，不用无限 shimmer；保留布局。
- `empty`：说明为什么为空和下一步，不当作错误。
- `stale`：有旧数据，显示截止时间并保留阅读能力。
- `degraded`：部分来源/字段降级，列明缺失和选用来源。
- `error`：无可靠数据；禁止展示占位数值或沿用结论。

页面级状态不能掩盖局部状态；例如行情正常但研究卡损坏，只降级研究卡。

## 10. API 与安全

- 浏览器只连接 `127.0.0.1` 的 FastAPI；V1 默认不监听局域网地址。
- CORS 只允许配置的本地 Next.js origin；不使用 `*`。
- 写操作使用同源本地 CSRF 防护/Origin 校验、幂等键和审计事件。
- 不渲染未清洗 HTML；研究卡按纯文本/受控 Markdown 渲染。
- 错误响应不泄露本地绝对路径、堆栈、Cookie 或请求密钥。

## 11. 性能预算

- 桌面本地首屏：冷启动可交互目标 ≤2.5s，缓存命中 ≤1.5s。
- API 缓存命中 P95 ≤200ms；本地聚合 P95 ≤800ms。
- 首页初始 JS 预算目标 ≤350KB gzip（ECharts 按需加载）；个股图表懒加载。
- 列表 300 行以内使用虚拟化或分页；图表只保留可视窗口必要点。
- 页面刷新/轮询不造成布局跳动、缩放重置或持续主线程长任务。

## 12. 页面完成定义

每个页面必须同时满足：真实/固定 fixture 数据可渲染；五态齐全；来源/时间可见；桌面/手机/iPad 实测；键盘焦点与屏幕阅读语义；API 错误可恢复；无装饰性金融数据动画；关键 E2E 和视觉截图通过。
