本文件把用户的口头规则固化为可审计的回测协议。本轮只定义规则、数据契约和验收门，不启动回测，也不修改当前 V1 Web 页面。只有“执行前硬阻塞项”全部关闭并生成冻结版策略后，系统才允许产生正式结果。

机器可读配套文件：[策略配置](../config/dividend-hurdle-backtest-v1.yaml)、[策略 Schema](../schemas/dividend-hurdle-backtest-policy.schema.json)、[账本快照 Schema](../schemas/backtest-ledger-snapshot.schema.json)和[可复算账本样例](../templates/backtest-ledger-snapshot.example.json)。

## 1. 要检验的命题

对经营质量通过严格门槛的成熟 A 股，在历史时点仅使用当时已经公开的信息：

1. 用保守年度现金分红估计除以当时未复权股价，计算税前股息率；
2. 当股息率不低于同期个人大额存单信号利率加 `3.00` 个百分点时，允许持有；
3. 当股息率严格低于该门槛时退出；
4. 每次新建仓固定买入 `1000` 股，最多同时持有 `20` 只；
5. 现金分红不自动复投，卖出后可在未来月度筛选中重新入选。

本策略不是“固定初始资金组合”。它采用按需外部注资并复用账户现金，因此必须同时报告资金加权收益和时间加权收益，不能把累计买入额当成本金，也不能把简单收益率包装成常规基金净值。

## 2. 已冻结的核心规则

### 2.1 标的池与 20 个席位

- 使用每个历史时点真实存在的普通 A 股；保留后来退市的股票，禁止用今天的存续股票名单回看历史。
- 排除当时的 ST、`*ST`、退市整理、暂停上市、无法正常交易或数据质量未过门的标的。
- 所有权类型不是硬门：央企属性作为标签展示；另做“仅中央企业”敏感性检验。
- 每个标的必须有最近 `3` 个在信号时点已经完整获知的财年现金分红观察值，其中“不分红”按 `0` 纳入中位数。
- 主组合最多 `20` 个同时持仓席位。已有持仓占用席位，不因月度排名下降被动卖出；只在空缺席位上建仓。
- 已触发退出但尚未实际卖出的持仓仍占用席位，直到卖出成交或按真实终止事件结算。
- 候选超过空缺席位时，按“股息率超过门槛的安全垫”从高到低选择；再依次按分红观察完整度、过去 20 个交易日成交额中位数、证券代码排序打破并列。
- “所有合格股票各买 1000 股”仅作为容量诊断，不作为主组合收益结果。

### 2.2 质量门

质量门只能使用 `known_at <= signal_at` 的数据，并按行业分别判断：

- 通用门：证券身份、上市/风险/交易状态、审计意见、持续经营重大不确定性、重大违法退市风险、财务数据完整性。
- 非金融企业：盈利持续性、经营现金流、偿债与分红覆盖能力。
- 银行：监管资本、资产质量、拨备与盈利状态；不得用工业企业经营现金流规则替代。
- 保险：偿付能力、监管风险评级与盈利状态。
- 券商：净资本及风险控制指标、监管状态与盈利状态。

数值阈值和生效期必须另行形成版本化规则。当前尚未冻结，因此策略保持 `DRAFT_NOT_EXECUTABLE`。质量恶化在持有期内只生成警告，不触发本策略的自动退出；这样可以单独检验“股息率门槛退出”的效果，避免事后混入第二套卖出逻辑。

### 2.3 保守分红口径

所有比例在机器数据中以小数保存，例如 `0.045 = 4.5%`。

在信号时点 `t`：

```text
D_ttm(t)  = 过去 365 日内除权日已经发生、且当时已知的每股现金分红之和
D_med3(t) = 最近 3 个已完整获知财年的每股现金分红中位数（含 0）
D_cons(t) = min(D_ttm(t), D_med3(t))
Y(t)      = D_cons(t) / P_raw_close(t)
```

约束如下：

- 核心结果纳入所有实际实施的普通和特别现金分红，不由研究者主观挑选；“排除特别分红”只做敏感性检验。
- 尚未除权的未来分红不进入 `D_ttm`，即使方案已经公告。
- 分红方案的公告/实施公告决定 `known_at`；除权日决定进入 TTM 的日期；派息日决定现金到账日期。
- 送股、转增、拆并股等只按当时已经发生的公司行动换算至信号时点每股口径。不得用今天的后复权或前复权序列改写历史信号。
- 核心信号使用税前现金分红；实际账户收益按当时有效税法和持股批次计税。

### 2.4 银行利率门槛

```text
H(t) = R_cd_signal(t) + 0.0300
```

`R_cd_signal` 是策略信号序列，不等同于“当天一定可以买到且适合本账户的大额存单收益”。两者必须分栏展示。

- 银行面板：工商银行、农业银行、中国银行、建设银行。
- 同期限至少有 `2` 家银行的合格观察值，取中位数。
- `2016-01-04` 至 `2017-12-31`：使用个人 `3` 年期大额存单信号利率。
- `2018-01-01` 起：优先个人 `5` 年期；同日/同一有效期样本不足时降级到 `3` 年期，并明确显示 `tenor_fallback=true`。
- 主回测只接受真实观察值，或来源明确写有有效期且信号日落在该有效期内的产品利率；不允许无证据向后延续，未核实延续天数固定为 `0`。
- 无足够真实样本时，门槛状态为 `UNAVAILABLE`：停止新增买入，不因缺失利率强制卖出现有持仓，并写入审计事件。
- “最近观察值最多延续 180 日”只能作为名称明确的独立敏感性实验，所有日期标记 `SYNTHETIC_CARRY`；不得进入主回测、主收益曲线或真实存款比较器。
- 另建“可投资存款比较器”，逐笔记录起购金额、发行期、期限、提前支取规则和当时是否可购买；在该数据未完成前，不得声称策略跑赢了真实可执行的大额存单组合。

大额存单的起购金额和发行条款会变化，不能只保留一个利率数字。规则依据包括：[2016 年个人大额存单起点调整资料](https://xining.pbc.gov.cn/chubanwu/114566/114579/3842271/3842532/2019061117433378190.pdf)及[大额存单管理/实施资料](https://www.chinamoney.org.cn/chinese/gzzd/20150624/1003037.html)。

### 2.5 信号、建仓与退出

每月第一个交易日收盘后筛选：

```text
允许入选：Y(t) >= H(t)
最大允许买价：P_limit(t) = D_cons(t) / H(t)
```

- 信号只使用当日收盘后可知的数据；不能以同日收盘价成交。
- 在下一可交易日开盘尝试提交 `1000` 股限价模拟单，限价为 `P_limit`。
- 基准成交价为未复权开盘价叠加不利滑点。若叠加滑点后的价格高于限价，整单不成交；不使用当天最低价事后“补成交”。
- 每次新建仓必须恰好 `1000` 股且整单成交；已有持仓不得重复买入、补仓或摊薄成本。
- 建仓失败后等到下一个月度筛选，不在月内反复追价。
- 月度信号只给排名进入空缺席位数量的候选下单；其中某笔开盘未成交时，不事后递补当月排名靠后的股票。
- 名义股价不设武断上限。界面必须显示 `1000 × 限价 + 预计费用` 的所需现金；若未来增加每单金额上限，必须升级策略版本，不能看完结果再添加。

持仓期间每个交易日收盘后检查：

```text
继续持有：Y(t) >= H(t)
触发退出：Y(t) <  H(t)
```

- 等于门槛时继续持有，只有严格小于才退出。
- 退出信号在下一可交易日开盘尝试卖出全部“公司行动调整后的实际股数”。
- 停牌、无成交的一字跌停、交易限制或流动性门导致无法卖出时，订单排队并逐日记录失败原因；禁止回填到首次信号日成交。
- 卖出完成后，该证券最早只能在此后的月度筛选重新入选并重新买入 `1000` 股。
- 主结果保持零迟滞带；另报告门槛附近穿越次数和交易成本。迟滞带只能作为预先声明的敏感性版本，不能据主结果调参。
- `D_cons`、原始价、银行利率或质量门任一关键输入不可用时：禁止新建仓，对已有持仓不据此强制退出，并记录 `DATA_GAP`；不得把缺失值当作 0。
- 同一开盘时点先处理已经可用的强制公司行动/到账现金，再处理卖出，最后按预先冻结的月度排名顺序处理买入；每笔买入仅在前序事件完成后按现金缺口注资。这样同日卖出所得可用资金可以复用，事件顺序不会随实现细节改变。
- 回测截止日不强制平仓：仍可交易的持仓按截止日未复权收盘价估值，不虚构卖出费用或红利税；无法可靠估值的终止标的按下一节的保守下界处理。

## 3. 公司行动、分红税与终止状态

- 现金分红：除权日确认应收，派息日进入共享现金；不自动复投。
- 差别化红利税：按批次持股期限和当时规则，在实际触发扣缴的时点记账；不得统一在派息日按固定税率扣除。税务依据参见[财政部、税务总局、证监会关于上市公司股息红利差别化个人所得税政策](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)。
- 送股、转增、拆股、合股：调整实际股数和单位成本，保留原始 `1000` 股建仓基数。
- 配股等自愿追加资金的公司行动：V1 默认不参与，记录权利放弃和稀释影响；不得悄悄追加股票数量或本金。
- 要约、吸收合并、现金选择权：只按当时真实可执行条款处理。
- 退市、长期停牌或终止上市：使用真实成交、现金补偿或清算回收；未知时不得按“最后收盘价”虚构卖出。主账户采用 `0` 的保守可变现下界，同时单列最后可观察参考值、日期和 `UNRESOLVED` 状态。

价格、除权与交易限制必须按当时生效的交易所规则解析；当前规则资料可从[上海证券交易所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)追溯，但历史回放必须使用对应历史版本。

## 4. 资金政策与账本公式

### 4.1 按需注资不是无限买入

- 初始现金为 `0`。
- 只有已通过全部规则且到达执行时点的买单才允许触发外部注资。
- 若共享现金不足，注资额恰好等于“本次成交总支出减可用现金”；不预存缓冲，不使用杠杆。
- 卖出和分红现金留在共享账户，可供以后建仓复用。
- 最多 20 个持仓席位限制了同时占用资金；累计外部投入仍可能随历次交易增加，因此必须完整展示资金流。
- V1 不主动取出现金；如以后允许提款，提款必须是独立外部现金流事件。

### 4.2 总账户

```text
即时总资产 = 现金 + 分红/其他应收 + 持仓市值
即时权益   = 即时总资产 - 已确认负债
总盈亏     = 即时权益 + 累计外部取出 - 累计外部投入
简单总盈亏率 = 总盈亏 / 累计外部投入
```

当累计外部投入为 `0` 时，简单总盈亏率为 `null`，不能除以零。

界面至少同时展示：

- 累计外部投入、累计外部取出、净外部投入；
- 累计买入成交额、买入费用、累计卖出成交额、卖出费用；
- 现金、分红应收、持仓市值、即时总资产、即时权益；
- 总盈亏、简单总盈亏率、资金加权收益率（XIRR/MWRR）、时间加权收益率（TWR）；
- 已实现/未实现盈亏、税费、滑点、不可成交次数、未解决估值数量。

资金加权收益以投资者视角记录：注资为负现金流，取出和期末权益为正现金流。TWR 在每次外部资金流时切分子期间，用资金流前后估值链接，避免后期新增本金把早期收益稀释或放大。

### 4.3 单股子账

每只股票的页面必须区分：

- `累计买入成本（含费）`：所有建仓轮次的买入支出总和，不等于外部本金；
- `当前持仓成本`：仅当前未平仓批次的成本；
- `当前市值`：实际股数乘最新合格原始价格；
- `累计净卖出回款`、`累计税后分红`、`当前分红应收`；
- `生命周期价值 = 累计净卖出回款 + 累计税后分红 + 当前分红应收 + 当前市值`；
- `单股累计盈亏 = 生命周期价值 - 累计买入成本（含费）`；
- 每一笔信号、下单、注资归因、成交、失败、分红、扣税、公司行动和估值事件。

共享现金可能已经被其他股票复用，因此“生命周期价值”不是一个隔离子账户的可提现余额。界面不得把它标成“该股当前现金”。

卖出净回款只扣除佣金、印花税、过户费等交易成本；差别化红利税归入“分红税”，从累计税后分红中扣除。即使红利税在卖出时实际扣缴，也不得同时从卖出回款和分红净额重复扣除。

### 4.4 账本闭合

每个快照至少校验：

```text
现金期初 + 外部净流入 + 卖出净回款 + 分红到账
- 买入总支出 - 税费 - 其他现金公司行动 = 现金期末

期初股数 + 买入股数 - 卖出股数 + 公司行动股数变化 = 期末股数

即时权益 + 累计外部取出 - 累计外部投入 = 总盈亏
```

误差容忍上限为 `0.01 CNY`。任一闭合失败即暂停生成绩效结果，写入审计事件，不允许前端自行修正。

## 5. 成本与执行情景

正式回测至少并行输出三套执行结果，使用同一信号：

- 乐观：低滑点、规则允许范围内较有利成交；
- 基准：按流动性分层的不利滑点和实际费用；
- 压力：更高滑点、延迟成交、涨跌停/停牌和部分流动性冲击。

逐笔成交必须拆出：券商佣金及最低收费、印花税、过户费、经手/监管等费用、其他现金费用、差别化红利税和滑点归因。规则如下：

- 所有法定费用按成交日期、买卖方向、交易所和当时有效版本计算，不能把 2026 年费率套回 2016 年。
- 券商佣金率及最低收费是账户参数，不假定所有券商相同；正式运行前必须冻结所模拟的券商费率档案。
- 滑点已经反映在模拟成交价中，只单列归因金额，不得再作为现金费用扣第二次。
- 差别化红利税按持股批次在实际扣缴事件记账，与卖出交易税费分开，不能重复扣减。
- 买入总支出等于成交金额加现金交易费用；卖出净回款等于成交金额减现金交易费用；最终盈亏、XIRR 和 TWR 均使用扣费后的真实账本现金流。

印花税历史变更可参考[财政部 2023 年减半征收证券交易印花税公告](https://www.mof.gov.cn/caizhengshipin/caizhengxinwen2/202308/t20230828_3904230.htm)，过户费参考[中国结算收费标准](https://www.chinaclear.cn/zdjs/editor_file/20220701154723234.pdf)，但最终数据集必须包含整个回测区间的有效期记录。当前费用与滑点版本未冻结，策略不可执行。

## 6. Web 查验契约（待现有 Web 任务完成后接入）

Web 只读取后端生成并通过 Schema 的结果，不自行计算金融数值。详情页至少提供：

1. 运行状态、策略/规则/费用/数据版本、数据截止时点和当前处理日期；
2. 总账户资金卡、权益曲线、外部现金流标记、TWR 与 MWRR；
3. 20 个持仓席位及历史轮次；
4. 单股资金与盈亏拆解、逐笔操作记录；
5. 每次买卖信号的 `D_ttm`、`D_med3`、`D_cons`、原始价、股息率、银行期限/利率、门槛和证据；
6. 费用、税、滑点、排队未成交、公司行动、数据降级与估值未解决事项；
7. 每日/每月 checkpoint，可按日期回看当时系统看到的全部输入；
8. loading、empty、stale、degraded、error 五态，且陈旧数据不能伪装为实时。

Web 接入不得成为回测运行时依赖；即使页面关闭，确定性后端仍能写入检查点并恢复。用户可以从任何买卖记录跳到原始证据和公式输入，复算出同一结果。

- 合格候选池等权、不择时基线；
- 只按质量门、忽略利率择时的基线；
- 可投资存款比较器（仅在产品条款证据完整后）；
- 仅央企、排除特别分红、门槛迟滞带、180 日银行利率推算、全合格股容量诊断等预注册敏感性结果。

除收益、年化和回撤外，必须报告外部投入峰值、XIRR、TWR、换手、费用、税、滑点、不可成交率、门槛穿越次数、候选/持仓覆盖、数据缺失天数和未解决估值。不能只给一个最终收益率。

## 8. 防时间穿越与中立性检查

- 财务数据按首次公开时间进入，不按报告期末提前进入。
- 分红、银行利率、指数成分、行业、ST、停牌、上市/退市状态均使用历史版本。
- 原始行情用于信号和成交；复权序列只可用于明确标注的总回报分析。
- 每个派生字段保留来源、发布时间、抓取时间、`known_at`、转换版本和质量等级。
- 输入不足时返回 `UNKNOWN/UNAVAILABLE`，不得猜值或用今天的数据补历史。
- 正式主回测的原始数据模式必须为 `REAL_POINT_IN_TIME`，合成原始观察数量必须为 `0`。测试夹具只能用于机制单元测试，运行标识必须为 `MECHANISM_TEST`，其结果不得进入绩效页面。
- 股息率、三年分红中位数和四行利率中位数属于由真实输入确定性计算的派生值，不属于假数据；滑点与成交情景属于显式模拟假设，必须与原始事实分栏展示。
- 测试集结果揭晓后禁止调门槛、20 个席位、排序、分红口径或卖出不等式。任何修改必须新建策略版本并重新划分验证期。
- 正式跑前先以不参与参数选择的边界样本验证：等于门槛、零分红、特别分红、跨期分红、送转后 1000 股、停牌、连续跌停、退市、红利税持股期限、费用变更日和银行期限降级。

## 10. 版本纪律

- 本版新增了 `20` 个同时持仓席位，解决“所有达标股票均买入导致组合规模不可比”的问题。
- 本版明确按需注资、共享现金复用，以及“累计外部投入”与“累计买入成本”的区别。
- 本版将银行信号利率与真实可购买存款比较器分开，禁止把延续利率冒充可购买产品。
- 本版将普通/特别现金分红全部纳入核心口径，特别分红排除仅作敏感性检验。
- 本版补充批次红利税、公司行动、退市未解决估值、开盘限价成交和门槛缺失时的降级规则。

后续只允许把阻塞项从“未知”补成有证据的冻结值；任何改变策略经济含义的修改都必须升级 `policy_version`，不得覆盖本文件的历史版本。

## 11. 实现前必须通过的边界用例

| 编号 | 输入/事件 | 唯一预期结果 |
|---|---|---|
| DH-001 | `Y == H`，有空席位 | 允许入选；持仓不退出 |
| DH-002 | `Y` 比 `H` 低最小可表示精度 | 已持仓生成退出信号 |
| DH-003 | 20 个席位已满，第 21 只合格 | 不下买单，也不挤出已有持仓 |
| DH-004 | 退出已触发但卖单未成交 | 仍占席位，不能提前补位 |
| DH-005 | 已持有股票再次进入月榜 | 不重复购买 1000 股 |
| DH-006 | 某股票卖出后在下一个月度筛选再次合格 | 新建独立轮次并买入 1000 股 |
| DH-007 | 次日开盘叠加滑点高于 `D_cons/H`，盘中最低价后来跌破限价 | 整单不成交；不得用盘中低价补成交 |
| DH-008 | 当月入围买单失败 | 当月不递补榜外候选，下月再筛 |
| DH-009 | 银行序列超过 180 日无合格观察 | 禁止新仓；已有仓不强制退出；记录缺口 |
| DH-010 | 分红、价格或质量门关键输入缺失 | 与 DH-009 相同，未知值不得当 0 |
| DH-011 | 五年期样本不足但三年期有至少两家 | 使用三年期并标注期限降级 |
| DH-012 | 尝试在主回测中使用 180 日延续银行观察值 | 主回测拒绝；只能进入独立 `SYNTHETIC_CARRY` 敏感性实验 |
| DH-013 | 分红方案已公告但尚未除权 | 不进入 `D_ttm`，也不进入账户应收 |
| DH-014 | 除权日已到、派息日未到 | 进入 `D_ttm` 和分红应收，不增加现金 |
| DH-015 | 派息日到达 | 应收减少、现金等额增加，权益不因搬账跳变 |
| DH-016 | 最近三个已知财年中一年明确不分红 | 该财年以 0 进入中位数 |
| DH-017 | 实际实施的特别现金分红 | 核心口径纳入；排除版只出现在敏感性结果 |
| DH-018 | 1000 股发生 10 送 5 | 实际数量变 1500，原始建仓基数仍为 1000，退出卖 1500 |
| DH-019 | 发生自愿配股 | V1 不认购，不追加本金，记录放弃权利与稀释 |
| DH-020 | 卖出时扣缴历史分红税 | 只记入分红税一次，不重复扣减卖出净回款 |
| DH-021 | 同一开盘既有卖出又有买入 | 先卖后买；卖出可用资金先复用，仅对剩余缺口注资 |
| DH-022 | 账户现金 3000 元，新买单总支出 10010 元 | 外部注资恰为 7010 元 |
| DH-023 | 累计外部投入为 0 | 简单收益率为 `null`，不得显示 0% 或无穷大 |
| DH-024 | 截止日仍有正常持仓 | 按当日原始收盘价估值，不强制虚构卖出 |
| DH-025 | 终止标的没有可靠成交/补偿结果 | 可变现值按 0 下界计，单列最后参考值和未解决状态 |
| DH-026 | 财报或公司行动发布时间晚于信号时点 | 时间穿越检查失败，该输入不得进入信号 |
| DH-027 | 同一时点发生送转、到账、卖出和买入 | 严格按冻结事件顺序处理，重复运行结果一致 |
| DH-028 | 买卖跨越费用或税率生效日 | 分别使用各自日期有效版本，不沿用单一现行费率 |

上述用例只验证机制，不用来选择 3 个百分点、20 个席位或其他参数。
