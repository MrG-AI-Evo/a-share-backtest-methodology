# 回测方法交接

## 1. 权威文件与版本关系

当前默认运行策略是 `config/dividend-hurdle-backtest-v4.yaml`，继承 V1 经济规则及其 SHA-256，主窗口由后续运行策略指定。V1 文档中的旧窗口不能覆盖 V4。不要修改 V1 内容来修复路径，否则会破坏基线哈希。

正式 CORE20、固定样本 pilot、日常 paper 模拟盘是三种不同场景：CORE20 是零初始现金、按需注资、最多20席位；paper 的100万元初始资金和仓位风险参数不能混入 CORE20；11/31股 pilot 带事后选样偏差、利率/质量规则简化，只能作机制测试。保留所有策略配置供审阅，不把 pilot 的规则冒充正式经济规则。

## 2. 信号与选股

以 `known_at <= signal_at` 为输入边界。所有信号与成交价格用未复权价，分红每股口径只按当时已生效的公司行动换算。

```text
D_ttm = 过去365日内已除权且当时已知的每股现金分红合计
D_med3 = 最近3个已完整获知财年的每股现金分红中位数（明确不分红计0）
D_cons = min(D_ttm, D_med3)
Y = D_cons / raw_close
H = R_cd_signal + 0.0300
P_limit = D_cons / H
```

普通及特别现金分红均纳入；已公告但未除权的未来分红不得进入信号。缺失分红年度不是0。

正式银行面板为工、农、中、建四行，同期限至少2家合格观察后取中位数。2016–2017使用3年期；2018起优先5年期，不足则降级3年期并标记。只在有证据的有效期内使用，不无依据延续。180日延续仅能作为标注 `SYNTHETIC_CARRY` 的独立敏感性方案。

每月第一个交易日收盘通过身份、交易状态、质量与股息门槛后，按股息率超额、分红完整度、20日成交额中位数、代码排序填空席。已有持仓不因重排名卖出，不重复买入；待卖未成交仍占席位。

## 3. 成交与退出

下一可交易日开盘，未复权开盘价叠加不利滑点后不高于限价，且满足交易规则与流动性约束，才可整笔买入1000股。失败等下个月，月内不追价，不事后递补榜外股票，不用盘中最低价补成交。

每日收盘 `Y < H` 才触发退出；等于门槛继续持有。次日尝试卖出公司行动调整后的全部实际股数；停牌或无法成交就排队并记录原因。关键数据缺失时阻止新买入，持仓保留并记录缺口，不把未知解释为卖出信号。

同一开盘严格依次处理：已生效公司行动/到账 → 卖出 → 按冻结排名买入 → 估值。不能按数据读取顺序改变现金复用或注资额。

## 4. 账本与收益

初始现金0；每笔可执行买单只对现金缺口注资，无杠杆。卖出和分红现金留在账户复用。除权确认应收，派息转现金；按持股批次与生效法规扣缴红利税。滑点已体现在成交价，不作为额外费用二次扣减；卖出费用与分红税分别归因。

```text
权益 = 现金 + 应收 + 市值 - 已确认负债
累计盈亏 = 权益 + 累计外部取出 - 累计外部投入
年度盈亏 = 年末权益 + 当年取出 - 年初权益 - 当年注入
简单盈亏率 = 累计盈亏 / 累计外部投入（投入为0时为null）
```

同时报告 XIRR/MWRR、TWR、回撤、外部投入、费用、税、滑点、不可成交与缺口。逐笔现金、股数、总账户、单股子账闭合，金额容差0.01 CNY。截止日不虚构卖出；终止标的无法可靠回收时按规则给出保守下界并显式标记未解决。
